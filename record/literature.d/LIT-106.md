# LIT-106: FlashAttention-2: Faster Attention with Better Parallelism and Work Partitioning

Dao et al. (2023) — [ARXIV-2307.08691](https://arxiv.org/abs/2307.08691)

## Key takeaways

- **The diagnosis.** FlashAttention reaches only **25–40% of theoretical
  peak FLOPs/s** — far short of an optimised GEMM — and the cause is
  "suboptimal work partitioning between different thread blocks and warps",
  producing low occupancy or unnecessary shared-memory traffic. Not the
  algorithm
- **Three changes**: reduce **non-matmul FLOPs**, which cost out of
  proportion because tensor cores run matmul far faster than anything else;
  **parallelise across thread blocks even for a single head**, adding the
  sequence-length dimension so occupancy survives a small batch × heads; and
  **distribute work between warps** inside a block to cut shared-memory
  communication
- **~2× over FlashAttention**, reaching **50–73% of peak**
- Forward-pass FLOPs are `4 · seqlen² · head_dim · n_heads`; the backward
  pass runs 5 matmuls to the forward's 2, because of recomputation
- **Block sizes are hand-tuned**, not derived: `{64,128} × {64,128}`, chosen
  per head dimension against device shared memory — "essentially only 4
  choices". This is a departure from FlashAttention's `B_c = ⌈M/4d⌉`
