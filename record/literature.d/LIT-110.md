# LIT-110: Efficiently Scaling Transformer Inference

Pope et al. (2022) — [ARXIV-2211.05102](https://arxiv.org/abs/2211.05102)

## Key takeaways

- The core move is to write down an analytical cost model for the partitioning of a transformer across chips — weights, activations and KV cache each with their own memory and communication terms — and then select the layout that model says is best, instead of reusing the training layout.
- The best layout is not one layout. A latency-optimized target and a throughput-optimized target want different partitionings of the same model, and the paper gives both alongside the regime where each wins.
- Memory bandwidth, not arithmetic, is the binding constraint in decode, and the KV cache is the term that grows with batch and sequence — which is what makes cache layout and access pattern the thing to optimize.
- Multiquery attention is analyzed as a way of shrinking that term, enabling much longer contexts at a given memory budget.
