# LIT-804: Relational inductive biases, deep learning, and graph networks

Battaglia, Hamrick, Bapst, Sanchez-Gonzalez, Zambaldi, Malinowski,
Tacchetti, Raposo, Santoro, Faulkner, Gulcehre, Song, Ballard, Gilmer, Dahl,
Vaswani, Allen, Nash, Langston, Dyer, Heess, Wierstra, Kohli, Botvinick,
Vinyals, Li, Pascanu (2018) — [ARXIV-1806.01261](https://arxiv.org/abs/1806.01261)

## Key takeaways

- **The GN block** (Algorithm 1, Eq. 1): a graph is (u, V, E) with a global
  attribute u. Three update functions φᵉ, φᵛ, φᵘ and three aggregations
  ρ^{e→v}, ρ^{e→u}, ρ^{v→u}, which must be permutation-invariant and accept
  any number of inputs. Edges are updated first, then nodes, then the
  global attribute
- **The relational inductive bias** (§3.2.4): edges decide which entities
  interact, sets make the computation order-invariant, and per-edge and
  per-node functions are shared, so one block runs on graphs of any size
- **A unifying table** (§4.2): an MPNN is a GN whose ρ^{e→v} is a sum and
  whose readout takes no edge aggregate. Non-local networks and
  self-attention are GNs on fully connected graphs with attention-weighted
  aggregation
- **Stated limits** (§5.2): message passing cannot separate some
  non-isomorphic graphs, and recursion, control flow and conditional
  iteration are not natural on graphs. Where the graph comes from is named
  as the open question

## Standing in the anthology

**Filed from the graph-coverage pass** (gap list from the record's own
review, 2026-10-22).

It `extends` the MPNN framework ([LIT-829](LIT-829.md)), which it re-expresses in
§4.2.1: the MPNN's message function is the GN edge update without the
global input, its sum over neighbors is the GN's edge-to-node aggregation,
and its readout is the global update. What the GN adds is a global
attribute that every edge and node update can read, and explicit
per-layer edge states, which the MPNN paper had noted only one earlier
model used.

**A framework and an argument, not a result.** Its evidence for
combinatorial generalization (§5.1) is a review of other papers'
experiments, several of them by its own authors. The 1-WL limitation it
concedes in one sentence is the one GIN later made precise ([LIT-580](LIT-580.md),
[THEORY-083](../theory.d/THEORY-083.md)).
