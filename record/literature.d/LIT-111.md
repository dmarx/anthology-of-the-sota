# LIT-111: OnePose: One-Shot Object Pose Estimation without CAD Models

Sun et al. (2022) — [ARXIV-2205.12257](https://arxiv.org/abs/2205.12257)

## Key takeaways

- Category-level pose estimation
- Neural point representation
- Cross-instance generalization
- Efficient inference

## Standing in the anthology

**Carries no practice, and this is a reading rather than an assumption.**

One-shot object pose estimation. One-shot pose estimation from a neural point representation. The transferable half is the representation, which lands in the same unfilled gap as [LIT-064](LIT-064.md) and [LIT-086](LIT-086.md); the rest is a task pipeline.
