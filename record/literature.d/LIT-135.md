# LIT-135: Qwen3.8-27B

Qwen Team, Alibaba (2026) —
[Qwen3.8-27B model card](https://huggingface.co/Qwen/Qwen3.8-27B) and the
release post at qwen.ai (`blog?id=qwen3.8`, whose own title is
"Qwen3.8-Max: A New Bar for Coding and Cowork"). No paper; the third
`url:`-only source in the record.

## Key takeaways

- Released 14 August 2026 under Apache 2.0: 27.78B parameters, dense, with
  a 27-layer vision encoder for image and video, a 262,144-token native
  context extensible to 1M, and a multi-token-prediction head shipped in
  the checkpoint for EAGLE-style speculative decoding.
- The language model is a 64-layer, 5120-hidden hybrid: 48 Gated DeltaNet
  linear-attention layers (48 value heads, 16 query/key heads, 128-dim) and
  16 gated full-attention layers (24 query heads, 4 KV heads, 256-dim) —
  three linear layers to one global, so only 16 layers carry a KV cache.
- The configuration is the same as Qwen3.6-27B's: same `model_type`, layer
  count, hidden size, hybrid layout, vision depth, context and MTP setup.
  What changed in four months is post-training. The 3.8 card re-evaluates
  both in one harness and reports Terminal-Bench 2.1 73.0 vs 63.4,
  SWE-bench Pro 61.7 vs 53.5, QwenSWEBench 79.0 vs 49.3, with smaller
  gains on plain reasoning.
- Thinking mode is on by default and can be disabled per request.
  `reasoning_effort` takes `xhigh`, `medium` or `low`, and the default is
  `xhigh` — the deepest of the three, described as being for complex tasks
  demanding thorough analysis — so the out-of-the-box configuration is the
  expensive one. `preserve_thinking` is likewise on by default, carrying
  reasoning context forward from earlier messages.

## Standing in the anthology

Filed as the current dense instance of the design Qwen3-Next introduced
([LIT-136](LIT-136.md)) and Qwen3.5 and 3.6 carried: Gated DeltaNet ([LIT-137](LIT-137.md)) for three
layers in four, gated attention ([LIT-138](LIT-138.md)) for the fourth. It is the second
independent adopter of the 3:1 hybrid in the record, with a different
linear module from Kimi's ([LIT-133](LIT-133.md)), which is what let [SOTA-132](../practices.d/SOTA-132.md) stop
calling that replication missing. The pretraining recipe for this
checkpoint is still not published, and nothing here is sourced to the card
beyond the architecture — but the generation's design work now is
([LIT-152](LIT-152.md)), for a different model in the same family.
