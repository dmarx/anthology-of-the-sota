# LIT-004: Training Deep Nets with Sublinear Memory Cost

Chen et al. (2016) — [ARXIV-1604.06174](https://arxiv.org/abs/1604.06174)

## Key takeaways

- Introduces gradient checkpointing
- Reduces memory usage with minimal computation overhead
- Enables training deeper networks
- Trade-off between memory and computation

## Standing in the anthology

**Audited by [#121](https://github.com/dmarx/anthology-of-the-sota/issues/121). Unsourced, unread, and the most valuable
unread document the audit found.**

This is a generic-bullet note that survived the pass that cleared the rest of
them — its four takeaways name the category ("introduces gradient
checkpointing", "trade-off between memory and computation") rather than the
method, which is the signature that pass was written to catch. It is recorded
here because the miss is informative: that pass selected on a bullet
*signature*, and a document can be equally empty without matching it.

The reason it matters is the gap it sits in. **The record recommends
recomputation only for attention** — [SOTA-087](../practices.d/SOTA-087.md), sourced to
[LIT-074](LIT-074.md) — and holds no general statement of the memory/compute trade
that recomputation buys, despite it being universal in large-model training and
despite this paper being where it comes from. The practice registry has
twenty-nine `distributed-optimization` entries and none of them is about
activation memory as such.

Nothing is filed from here, because filing a practice from four bullets that
describe the category is the failure this record has spent two passes
correcting. What it needs is a reading.
