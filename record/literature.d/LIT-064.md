# LIT-064: Instant Neural Graphics Primitives with a Multiresolution Hash Encoding

Müller et al. (2022) — [ARXIV-2201.05989](https://arxiv.org/abs/2201.05989)

## Key takeaways

- Real-time neural rendering
- Multi-resolution hash encoding
- GPU optimization
- Rapid training

## Standing in the anthology

**Carries no practice, and this is a reading rather than an assumption.**

Instant-NGP's contribution is a multiresolution hash encoding — an input representation that trades hash collisions for a small, GPU-friendly table, which is what makes the training fast. It is a real systems claim, but it is a claim about encoding *coordinates*, and the record holds no coordinate-network practice for it to sit beside. Filed as worth reading rather than recommended: a single practice drawn from it would have no siblings and no reader.
