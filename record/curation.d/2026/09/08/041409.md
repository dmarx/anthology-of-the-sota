title: 'The legacy flush: what came out, and what stayed'
created: '2026-09-08T04:14:09'
tags: [infrastructure]
---

Issue [#41](https://github.com/dmarx/anthology-of-the-sota/issues/41) asked for the pre-record Python to go. It was three tools sharing
one dependency: a README generator that assembled `README.md` and
`README_LLM.md` from Jinja templates, a directory summariser that wrote
per-directory prose into `docs/`, and a package-lock helper for a frontend
that no longer exists. All three imported `llamero`; the workflows that ran
them are gone with them.

Four things were checked before deleting anything, because each one could
have made a deletion lossy:

- **Nothing in the record referenced the modules.** The `[luria.code]` globs
  scanned `src/**/*.py` and `docs/**/*.j2`; with the templates gone the second
  glob names nothing, so it went too.
- **The templates were not templates.** `README.md` and `README_LLM.md` were
  concatenations of *static* fragments — no Jinja expressions in any of them —
  so the rendered files already in the tree are byte-complete, and the
  generator was rendering nothing. Deleting it loses no content.
- **`assets.logo.svg`** (the misnamed one at the repo root, a build artifact of
  an old workflow) is byte-identical to `assets/logo.svg`. Only the copy is
  gone.
- **`src/scripts/migration/`** stays. `CLAUDE.md` and [ADR-008](../../record/decisions.d/ADR-008.md) both promise the
  import stays re-runnable, and `to_record.py` needs only the standard library
  and `pyyaml` — so `pyproject.toml` shrank to that one dependency rather than
  disappearing.

The surprise was the test suite. It looked broken — `conftest.py` imports
`scripts.registry`, a module that has not existed for some time — so the first
read was "the tests are already dead, delete them." They were not: those
imports are inside fixture bodies, and the two tests that run never request
those fixtures. With `PYTHONPATH=src` the suite passed. The tests came out
because the code they covered came out, not because they were broken; the
distinction matters, because "already broken" would have been a reason to skip
checking what else the deletion took with it.

`README_LLM.md` was rewritten rather than trimmed. It had described
optional-dependency groups, a test suite, and a rule that "all workflows
depend on tests passing" — none of which survive, and two of which had not
been true for a while. A generated file that nobody regenerates decays into
a confident description of a repository that no longer exists.
