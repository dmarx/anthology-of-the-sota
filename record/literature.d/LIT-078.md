# LIT-078: An Image is Worth One Word: Personalizing Text-to-Image Generation using Textual Inversion

Gal et al. (2022) — [ARXIV-2208.01618](https://arxiv.org/abs/2208.01618)

## Key takeaways

- Personalizes a **completely frozen** text-to-image model by optimizing exactly
  one thing — a new token embedding `S*` inserted where tokens become vectors.
  No weights change; the model's vocabulary is expanded with a pseudo-word
- Frames the result on the **distortion/editability tradeoff** borrowed from GAN
  inversion, claiming a point on the curve rather than an escape from it
- Reaches **abstract concepts, not only objects**: a shared style is found by
  training on prompts of the form "A painting in the style of `S*`"
- **A decomposition worth stealing:** optimize a shared placeholder `S*` *and* a
  per-image placeholder `S_i` jointly, with prompts "A photo of `S*` with `S_i`",
  so the model puts the shared concept in the shared code and relegates
  per-image incidentals like background to `S_i`

## Standing in the anthology

Read — [NOTE-034](../notes.d/NOTE-034.md). Retagged to `adaptation-and-tuning`: nothing about the
generative model changes.

Nothing is sourced here; the record's adaptation practices are LoRA-shaped and
concern language models.

The finding with reach past the domain is the per-image decomposition:
**give nuisance variation its own parameters rather than hoping it averages
out.** That is a control variable, applied to learned embeddings, and the record
states it nowhere.
