# NOTE-tmpahrh6: Dynamics of stochastic gradient descent for two-layer neural networks in the teacher-student setup

## Contribution

Derives exact ODEs for the learning dynamics of a two-layer ReLU student
network trained on synthetic data generated by a teacher network (teacher-
student setup). The ODEs track overlaps Q (student-student: W_i · W_j /
||W||^2) and R (student-teacher: W_i · W*_k / (||W|| ||W*||)) through time.
Shows that these scalar order parameters fully characterize the MSE and
alignment trajectory in the thermodynamic limit (N→∞, n→∞, n/N → const).
Introduces the "hidden manifold model" where data lies near a low-
dimensional teacher manifold.

## Key insight

In the teacher-student two-layer ReLU setup, the high-dimensional weight
dynamics compress exactly onto a small set of scalar ODEs. The student-
teacher overlap R captures "how aligned are student neurons to teacher
directions" and the student-student overlap Q captures "how redundant are
student neurons." The learning trajectory is: (1) specialization phase —
students differentiate and each aligns to a different teacher neuron; (2)
refinement phase — overlaps increase toward teacher values. The gossip
averaging step directly perturbs R by averaging across workers, potentially
re-merging specialized student neurons and forcing a re-specialization
phase.

## Assumptions

- Thermodynamic limit: d, H, N_local → ∞ with fixed ratios
- Online SGD (one sample per step; batch results follow from noise scaling)
- IID Gaussian inputs
- Fixed teacher (no teacher learning)
- Activation function: erf or smooth approximation to ReLU (exact analysis)

## Key results

- **Theorem (informal).** The test MSE and all overlaps Q, R satisfy a
  closed system of ODEs in the thermodynamic limit. These ODEs have a unique
  fixed point corresponding to the global minimum (perfect student-teacher
  alignment) when H ≥ H*.
  *Holds when:* Requires H ≥ H* (number of student neurons ≥ teacher
  neurons)
- **Empirical.** The ODE predictions match stochastic simulation results for
  d ≥ 50 to within 2–5%.
  *Holds when:* Gaussian data; erf activation; H* = 2, H = 4

## Concepts

- **Student-teacher overlap R** — R_{ik} = W_i · W*_k / (||W_i|| ||W*_k||);
  cosine similarity between student neuron i and teacher neuron k. R=1 means
  perfect alignment.
- **Student-student overlap Q** — Q_{ij} = W_i · W_j / (||W_i|| ||W_j||);
  redundancy among student neurons. Q=I means fully specialized (distinct)
  neurons.
- **Specialization phase** — Early training phase where students
  differentiate from each other; Q_ij → 0 for i≠j.
- **Refinement phase** — Late training phase where R_ik increases toward 1
  (student neurons converge to teacher directions).
- **Hidden manifold model** — Data x = F(c) where c is a low-dimensional
  latent code and F is a random feature map; generalizes pure Gaussian
  assumption.

## Limitations

- Thermodynamic limit analysis — finite-d, finite-H corrections may be
  significant.
- Online SGD only; minibatch version requires additional noise analysis.
- Activation: erf or similar; not exact ReLU.
- Teacher and student both two-layer; does not cover deeper architectures.

## Open questions

- Can the ODE be extended to the gossip setting — i.e., write an ODE for the
  averaged overlaps across N workers?
- What is the expected perturbation to R from a single gossip step as a
  function of H and the current overlap values?
- Do warm-started gossip workers (T16 experiment) start in the refinement
  phase, reducing the setback from averaging?
