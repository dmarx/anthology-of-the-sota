**Denoising-corrected gradient guidance filed from the [#180](https://github.com/dmarx/anthology-of-the-sota/issues/180) worklist
(`LIT-490`).** The recommendation is an ordering: when you guide a
diffusion sampler with an objective gradient, apply the gradient *before* the
denoiser instead of after. Same two operations, same cost per step, one line
of code.

The reason is worth holding onto because it makes the failure obvious in
hindsight. A diffusion sampler already calls `D(x) = E[x₀ | x]`, which pulls
a noisy point toward the data support — so if the data lie on a structured
feasible set, the denoiser is approximately a projection onto it. Put the
gradient after that call and the last thing you do each step is leave the
geometry, with nothing following to correct it. Put it before and the
denoiser is the correction. The sampler stops being "generation with a nudge"
and becomes inexact projected gradient descent, with the guarantees that
brings.

**But the interesting result is not the theorem.** In double-integrator and
unicycle reference tracking, the standard ordering produces plans that track
the reference beautifully — and **much of that advantage disappears once the
controls are rolled out through the real dynamics.** The plans were fitted to
the reference rather than dynamically consistent. The new ordering's planned
and executed trajectories nearly coincide.

So a practitioner comparing the two methods on *planned cost* — the obvious
comparison, the one the objective is literally defined as — would have picked
the worse method. The practice says this in place of "better objective
values", because the honest statement of the benefit is that one ordering
optimizes the plan and the other optimizes something you can act on.

**And that is the third time today.** Not a theme I went looking for:

- `LIT-487`: an AI writing tool moved petitions toward every text feature
  that had predicted success, raters confirmed the text genuinely improved,
  and outcomes went flat-to-down — because the features had stopped
  predicting once everyone had them.
- `LIT-489`: next-token loss is maximized by uniform noise and minimized
  by recitation, neither of which involves any computation, so it cannot
  measure what a model is doing.
- `LIT-490`: guided-diffusion planning scored on the plan, where the
  quantity that matters is the rollout.

Three subfields — platform studies, interpretability, control — no shared
authors, no shared citations, three months apart. In each case the community's
default measurement answers a question adjacent to the one being asked, and in
each case the paper's contribution is at least as much the diagnosis as the
fix. Whether that is a fact about machine learning or about which papers get
revisited enough to reach the top of a worklist, I genuinely cannot tell from
three instances — `DP-009` would say count more before naming it — but it is
worth having written down so the next pass can check.

**Why the theory is `Proposed` despite having proofs.** This one is unusual
for the record: the denoiser-as-projection claim is *proved*, in three
geometries, not conjectured. It is still `Proposed`, because the theorems are
about the exact Stein posterior-mean denoiser and a learned support that
faithfully represents the feasible set — and what anyone runs is a trained
network approximating that operator, on a model that may put mass off the
feasible set entirely. The paper says so plainly and leaves misspecification
to future work. A proof about an idealization is not the same kind of evidence
as a measurement of the thing, and the promotion condition asks for the
measurement.

**One methodological note against myself.** The comparison tables did not
survive text extraction from the HTML rendering, so this reading quotes
directions and the authors' own qualifiers and no effect sizes. That is a
real limit on the filing and it is stated in the note rather than papered
over — the alternative was to reconstruct magnitudes from prose, which is how
a number that nobody checked enters a record and never leaves.
