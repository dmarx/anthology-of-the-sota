# LIT-081: GPTQ: Accurate Post-Training Quantization for Generative Pre-trained Transformers

Frantar et al. (2022) — [ARXIV-2210.17323](https://arxiv.org/abs/2210.17323)

## Key takeaways

- The problem with round-to-nearest is that it treats weights as
  independent. They are not: the layer's output error depends on how the
  weights interact, so a rounding error made in one column can be absorbed
  by adjusting columns that have not been quantized yet.
- The method quantizes column by column and compensates, using approximate
  second-order (Hessian) information estimated from a small calibration set.
  This is a one-shot procedure — no retraining, no gradient steps.
- The headline: 3- and 4-bit weight quantization of models up to 175B in
  roughly four GPU-hours, with accuracy close to the uncompressed baseline.
  Reaching 4 bits at that scale had previously meant quantization-aware
  training.
- It is weight-only. The win is memory footprint and bandwidth, which is
  what makes decode faster, and it does nothing for a compute-bound prefill.
- The calibration set is an input, not an implementation detail. A
  calibration distribution unlike the serving distribution is where this
  degrades.
