Unit 6 of `#342`, and the last of its Tier A. The unit is straightforward — a
characterized defect in a component 107 documents lean on, with a fix that
costs nothing — so this entry is mostly about the thing that only became
visible because unit 5 happened first.

## The coincidence

**Unit 5.** Activation outliers in language-model feature dimensions break INT8
quantization. Reported as an **emergent property**: sharp degradation above ~6B
and not below. A controlled study holding architecture fixed found the
sensitivity tracks weight decay, dropout, clipping and training dtype instead.

**Unit 6.** High-norm outlier tokens in ViT feature maps spoil attention maps
and dense prediction. They appear **only at ViT-Large and above**, **only after
a third of training**, around layer 15 of 40. Read alone, that is the same
story. The resolution is different: the model is using redundant patches as
scratch space because it has nowhere else to put global state, and giving it
dedicated slots removes the artifacts entirely.

Two units in a row, in different modalities, on phenomena called outliers, both
correlated with scale, both with the scale correlation turning out not to be the
explanation.

## What the pair is and is not

It is tempting to write this up as a finding: *activation outliers are never
really emergent.* That would be wrong twice over.

They are **different phenomena**. Feature dimensions across a whole model
against token positions within a sequence. One is about the numerical range of
a weight-activation product, the other about what a position encodes. Different
causes: a hyperparameter in one, a missing architectural affordance in the
other. Different remedies, applied at different times — set weight decay before
training, or add tokens to the sequence.

And the record's own rules say what the resemblance is worth. Two papers
reaching similar-shaped conclusions by unrelated routes is **not** two
measurements of one thing. `ADR-011` reserves `compared_against` for a
comparison somebody ran; nobody ran this one. So both documents state the
parallel and both state that it supports a **question rather than a
conclusion**: when an activation pathology appears above a size threshold, what
else changed at the same time?

That is worth having because in both cases the answer was something nobody was
holding fixed, and in both cases finding it required training the models
yourself.

The record can see the pair at all only because of `ADR-026` — file by the kind
of claim, not the domain it was found in. Under the old scheme these would be a
quantization document and a vision document and nothing would put them next to
each other.

## Why the theory is `Active` on one paper

Worth writing down because this session has filed several `Proposed` theories
on single sources and this one differs.

The difference is that **the account made a prediction and somebody tested it**.
The hypothesis is that the artifacts exist because the model needs scratch
space; the prediction is that supplying scratch space should relocate them; the
test is appending register tokens; the result is that the high-norm patch tokens
disappear entirely across three training paradigms.

Compare `THEORY-099` from unit 3, which is `Proposed`: its mechanism
(isotropic spectra) is measured *alongside* the effect rather than intervened
on, and the paper's own ablation selects blocks by a different criterion. And
`THEORY-100` from unit 5, also `Proposed`: the LayerNorm gain spread
correlates with degradation and nobody has manipulated it while holding the
optimizer fixed.

**A successful intervention derived from the hypothesis is worth more than any
number of correlations consistent with it**, and that is the line this record
should be drawing when it decides a status on one source. Not "how many
papers" but "did anyone act on it and get what the account predicted."

## Three qualifications the unit kept

Each cuts against the tidy version and each is in the documents:

- **OpenCLIP object discovery is slightly worse with registers.** The one
  evaluation where the fix does not help. Neither the paper nor the account
  explains it; the paper's analysis is in an appendix.
- **Registers do not close the gap.** DINOv2+reg reaches 55.4 corloc on VOC
  2007; the original DINO reaches 61.9. If artifacts were the whole difference,
  the gap would have gone. Something else about DINOv2 also costs object
  discovery and nobody has named it.
- **"Redundant" is a proxy.** Operationalised as cosine similarity to four
  neighbours, which stands in for what the model can afford to lose rather than
  measuring it.

## The finding about a held document

`LIT-599` is DINOv2, and the record reaches for it as a frozen feature
extractor. The paper says *"DINOv2 is surprisingly incompatible with LOST"* —
and object discovery was a task family the previous generation had advanced the
state of the art on. **35.3 corloc against DINO's 61.9.**

A better model that regressed a whole task family by nearly half, because of
artifacts nobody had characterized. That is the sharpest instance this session
has found of a pattern worth naming: **a thesis that holds on the evaluations
run is not the same as a thesis that holds.** `LIT-599`'s claim is that
curation plus scale gives general-purpose features; the qualifier belongs in the
note now.
